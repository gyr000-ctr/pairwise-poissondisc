# pairwise-poissondisc

## 题面（可直接粘贴）

泊松盘采样（Bridson）+ 变密度。约束：任意两点距离 ≥ 该位置最小半径；点全部落在区域内；同种子可复现；必须支持变密度场（半径随位置变化），且密度误差 ≤10%；1 万点不超过 400 ms；并发独立；非法半径/密度报错。验收：python -m pytest tests -q -k poisson。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 1 万点耗时
- 并发
- 极小半径
- 退化区域
- 种子边界

```bash
python -m pytest tests -q
```
